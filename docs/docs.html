API Reference

Explore the components and namespaces available in Pyxil 0.3. This documentation introduces the framework's core architecture, its main features, and the tools available to developers when building desktop games with Python.

Namespaces Overview

Namespace Purpose
Pyxil.Framework Core framework classes and game/window management.
Pyxil.Framework.Audio Core audio framework classes and audio playback.
Pyxil.Framework.Content Content loading and management through ContentManager.
Pyxil.Framework.Graphics Rendering, textures, and visual effects.
Pyxil.Framework.Input Input and I/O, including keyboard, mouse, and gamepad.
Pyxil.Framework.Utils Utilities that assist with game development.

Logging and Errors

Pyxil 0.3 features a structured logging system designed to record framework events and provide developers with relevant diagnostic information. Log entries include severity levels, timestamps, and source components, helping developers monitor application behavior and identify potential issues. Supported log levels include INFO, WARNING, ERROR, CRITICAL, DEBUG, and EVENT.

The framework also provides descriptive error messages to help developers understand failed operations, identify their causes, and find appropriate solutions.

Platform Support

Pyxil 0.3 is designed to support desktop environments across Windows, Linux, and macOS, with a focus on 64-bit systems. The framework aims to provide a consistent development experience across different operating systems and Python environments.

The framework is designed with application distribution in mind, allowing developers to explore packaging solutions such as PyInstaller, py2exe, and Nuitka when preparing their games for deployment.
