A simple, fast, and lightweight framework.

Pyxil is a fast, lightweight framework developed for the 1x1 Studio team. The framework consists of a simple API with a low learning curve; its goal is to serve as a successor to the old XNA for the Python language.

Pyxil, Beyond XNA.

Pyxil is a game development framework inspired by the architecture and philosophy of Microsoft XNA, bringing its concepts to the Python ecosystem.

Designed to offer a lightweight, modular, and accessible framework, Pyxil aims to simplify desktop game development by giving developers greater control over graphics systems, resource management, data input, and the game's execution cycle.
